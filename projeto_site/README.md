# 🛒 Projeto E-commerce Django

Este projeto é um sistema de e-commerce desenvolvido como parte do meu portfólio de Engenharia de Dados e Desenvolvimento Web.

## 🚀 Tecnologias Utilizadas
- **Python & Django:** Estrutura principal do backend.
- **MySQL:** Banco de dados relacional (migrado de SQLite).
- **Bootstrap:** Estilização responsiva do front-end.
- **PythonAnywhere:** Deploy em nuvem.

## ⚙️ Funcionalidades
- Cadastro de produtos via Admin.
- Upload de imagens de produtos.
- Página de detalhes do produto (Rotas dinâmicas).
- Integração com Banco de Dados MySQL.
